# MWall v0.3.1

1. **修复历史记录丢失**：此前保存历史记录时日期以 ISO-8601 文本写入，读取时却按数值解析，导致每次启动后“历史”页为空，并在下次应用壁纸时覆盖旧记录。现在读写格式一致，历史记录在重启和更新后都会保留；读取失败时会写入系统日志，不再静默丢弃。

如果升级到 0.3.0 后尚未应用新壁纸，原有历史记录仍保存在磁盘上，更新到本版本后会重新显示；已在此期间应用过壁纸的，旧记录已被覆盖，无法恢复。

## 下载与安装

- 已安装 v0.3.0：在“设置 → 日常使用”中点击“检查更新”，或在菜单栏图标的右键菜单中选择“检查更新...”，也可等待每日自动检查。
- 系统要求：macOS 14 或更高版本。
- Apple Silicon 机型下载 `MWall-v0.3.1-macos-arm64.zip`，Intel 机型下载 `MWall-v0.3.1-macos-x86_64.zip`。
- 解压后将 `MWall.app` 拖入“应用程序”。每个 ZIP 均附带 `.sha256` 校验文件，可在下载目录运行 `shasum -a 256 -c 文件名.zip.sha256`。

应用采用临时签名，尚未使用 Apple Developer ID 签名或通过公证。首次打开可能被 macOS 拦截；确认下载来源和校验值后，可在“系统设置 → 隐私与安全性”中允许打开。
