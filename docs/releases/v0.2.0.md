# MWall v0.2.0

1. **壁纸浏览**：在菜单栏中浏览本地、Unsplash 和 Wallhaven 壁纸，支持收藏、历史记录，以及当前桌面或所有 Spaces 的壁纸切换。
2. **二次元壁纸**：Wallhaven 默认筛选全年龄横向二次元壁纸，支持关键词、分类、分页及随机、最新、热门、收藏数和浏览量排序，可选 API 密钥保存在 macOS 钥匙串中。
3. **壁纸配色**：提供 Aether、忠实壁纸、柔和、鲜艳四种风格，同时生成浅色与深色主题，支持多种终端、Neovim、Pi、Codex CLI 和可选的 Codex App 配色同步。

## 下载与安装

- 系统要求：macOS 14 或更高版本。
- Apple Silicon 机型下载 `MWall-v0.2.0-macos-arm64.zip`，Intel 机型下载 `MWall-v0.2.0-macos-x86_64.zip`。
- 解压后将 `MWall.app` 拖入“应用程序”。应用启动后显示在菜单栏，不显示 Dock 图标。
- 每个 ZIP 均附带 `.sha256` 校验文件，可在下载目录运行 `shasum -a 256 -c 文件名.zip.sha256`。

应用采用临时签名，尚未使用 Apple Developer ID 签名或通过公证。首次打开可能被 macOS 拦截；确认下载来源和校验值后，可在“系统设置 → 隐私与安全性”中允许打开，无需关闭系统安全保护。

已知限制：Codex App 配色同步后需要重启目标应用；Codex CLI 需新建会话才能可靠载入更新后的主题。Wallhaven 的浏览量不是下载量，配置 API 密钥也不保证获得更高的请求额度。
