# MWall v0.3.0

1. **自动更新**：每 24 小时检查一次 GitHub Releases，也可在设置或菜单栏右键菜单中手动检查。发现新版本后可选择立即更新、稍后或跳过此版本；安装前会校验 SHA-256、Bundle ID、版本号和代码签名，完成后自动重启。
2. **新图标**：新增应用图标；菜单栏改用扁平单色图标，自动适配浅色、深色和高亮状态。
3. **Wallhaven 完整筛选**：支持与网页端一致的分类、内容分级（NSFW 需要 API 密钥）、排序与顺序、排行榜时间范围、分辨率、比例和颜色，可直接粘贴 wallhaven.cc 搜索链接导入全部条件。
4. **Herdr 配色**：新增 Herdr 同步目标，导出当前、深色和浅色主题，不改动其他设置。
5. **屏保同步**：应用壁纸时同时将系统“照片”屏保设为同一张图片，并兼容 macOS 的 `Linked` 与 `Desktop` 两种壁纸存储结构。
6. **收藏缩略图**：收藏的预览图单独持久保存，不再随图源缓存清理而丢失；旧收藏缺图时自动恢复。

## 下载与安装

- 系统要求：macOS 14 或更高版本。
- Apple Silicon 机型下载 `MWall-v0.3.0-macos-arm64.zip`，Intel 机型下载 `MWall-v0.3.0-macos-x86_64.zip`。
- 解压后将 `MWall.app` 拖入“应用程序”。应用启动后显示在菜单栏，不显示 Dock 图标。
- 每个 ZIP 均附带 `.sha256` 校验文件，可在下载目录运行 `shasum -a 256 -c 文件名.zip.sha256`。

v0.2.0 不含自动更新功能，需要手动安装本版本一次；此后的版本可在应用内自动更新。

应用采用临时签名，尚未使用 Apple Developer ID 签名或通过公证。首次打开可能被 macOS 拦截；确认下载来源和校验值后，可在“系统设置 → 隐私与安全性”中允许打开，无需关闭系统安全保护。

已知限制：Codex App 配色同步后需要重启目标应用；Codex CLI 需新建会话才能可靠载入更新后的主题。Herdr 首次需要手动选择 mwall-dark 或 mwall-light 主题。自动更新要求应用所在目录可写。
